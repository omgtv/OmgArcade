RETRO GAME CATALOG
==================

Open index.html in Chrome, Edge, Firefox, or Safari.
No web server is required; the game database is stored in games-data.js.

FEATURES
- 400+ system/collection sections
- Search systems
- Search games by title, ROM name, manufacturer, category, or year
- Filter by category and year
- Hide clone entries by default
- Select individual games or all visible filtered games
- Customer name/contact fields
- Persistent selections in the browser
- Copy an order summary
- Download order as TXT or CSV
- Responsive layout for desktop/tablet/mobile

CUSTOMIZATION
- Change the store/catalog name in index.html
- Adjust colors in the :root section of styles.css
- If you update the source ROM list, regenerate games-data.js from your source file.

IMPORTANT
Only offer/distribute game files you are legally authorized to reproduce or distribute.
